VoiceMate — Complete Android AI Voice Assistant MASTER PROJECT
SPECIFICATION & DEVELOPMENT GUIDELINE

Project name: VoiceMate Package name: com.voicemate.assistant Platform:
Android Primary languages: বাংলা, English এবং Bangla-English mixed
commands Minimum Android: Android 10 (API 29) Target compatibility:
Android 10–15, with future compatibility maintained where possible
Primary test device: Samsung Galaxy A17 5G

PROJECT GOAL একটি নিজস্ব Android voice assistant তৈরি করা, যেখানে Bixby,
Google Assistant এবং AI chat assistant-এর উপযোগী ফিচারগুলো একত্র থাকবে।
অ্যাপটি বাংলা ও ইংরেজি বুঝবে, ফোনের অনুমোদিত control, automation,
camera-based search, smart home এবং AI conversation দেবে।

প্রযুক্তি: - Kotlin - Jetpack Compose - Material 3 - MVVM - Clean

TextToSpeech - CameraX - ML Kit - Retrofit বা Ktor Client - Kotlin

থাকবে। - Feature-গুলো যতটা সম্ভব independent package/module হবে। - UI থেকে

ব্যবহার করবে। - Async কাজ Coroutine/Flow দিয়ে পরিচালনা করবে। - API error,

code-এ রাখবে না। - Sensitive data log করবে না। - Business logic
unit-testable হবে।

5.  Voice Core

5.1 Voice activation: - App button দিয়ে assistant চালু - Notification
action দিয়ে voice session শুরু - অনুমোদিত floating/overlay button - Wake
word: “Hey Mate” - Wake word পরিবর্তনের ব্যবস্থা - Voice input
enable/disable - Listening indicator - Cancel command - Stop speaking
command

Android-এ সব অবস্থায় সব সময় wake word শোনা সাধারণ অ্যাপের জন্য নিশ্চিত নয়।
Foreground service, microphone permission, notification, battery
restrictions, Android background-execution rules এবং SDK conditions
বিবেচনা করবে। Screen-off অবস্থায় সব ফোনে নির্ভরযোগ্যভাবে কাজ করবে বলে দাবি
করবে না। প্রথমে tap-to-talk তৈরি করবে, পরে wake-word prototype ও battery
test করবে।

5.2 Speech-to-Text: - Android SpeechRecognizer - বাংলা ও English
recognition - Bangla-English mixed commands - Partial/final results -
Timeout ও silence detection - Retry mechanism - Offline recognition
engine থাকলে ব্যবহার - Offline model না থাকলে user-কে জানানো

Offline speech recognition সব Android device-এ স্বয়ংক্রিয়ভাবে পাওয়া যায়
না। অনুপস্থিত capability-কে supported বলে দেখাবে না।

5.3 Text-to-Speech: - বাংলা ও English voice - Language switching -
Speech rate ও pitch - Voice preview - Stop speaking - Queue management -
TTS unavailable হলে error

বাংলা voice installed TTS engine-এ আছে কি না পরীক্ষা করবে। না থাকলে
compatible voice data ইনস্টল করার নির্দেশনা দেবে।

5.4 Voice Match: - ঐচ্ছিক voice profile enrollment - Local enrollment
interface - Identity verification-এর সীমাবদ্ধতা সম্পর্কে সতর্কতা - Voice
data deletion - False acceptance/rejection testing

সাধারণ voice recording-কে secure biometric authentication হিসেবে ধরবে
না। Sensitive action-এর একমাত্র authorization হিসেবে Voice Match ব্যবহার
করবে না।

5.5 Conversation context: উদাহরণ: “আজকের আবহাওয়া বলো।” এরপর “আর কাল?”
বললে আগের প্রসঙ্গ বুঝে আগামীকালের আবহাওয়া খুঁজবে। - Conversation session ID -
Recent context - Follow-up reference - Context expiration - Clear
history - Local/cloud context settings

অস্পষ্ট বা ঝুঁকিপূর্ণ command হলে অনুমান না করে প্রশ্ন করবে।

6.  AI ও Natural Language Understanding

6.1 AI provider: LLM API-এর জন্য provider abstraction তৈরি করবে। প্রথম
implementation-এ Gemini বা অন্য নির্বাচিত provider ব্যবহার করা যাবে। -
Online LLM - Local deterministic command parser - Future local model
adapter - Provider switching - Timeout ও rate-limit handling -
Usage/error status

Free API quota বা model access স্থায়ীভাবে free থাকবে বলে ধরে নেবে না।

6.2 Intent parser: উদাহরণ: - “ফ্ল্যাশলাইট চালু করো” →
device.flashlight.set - “আগামীকাল সকাল ৮টায় মনে করিয়ে দিও” →
reminder.create - “মায়ের কাছে কল করো” → communication.call - “এই ছবিতে
কী লেখা আছে?” → vision.ocr - “শুভ সকাল” → routine.execute

প্রতিটি intent-এ থাকবে ID, parameters, confidence, required permissions,
risk level, confirmation requirement ও action result।

6.3 Tool/function calling: LLM arbitrary Kotlin code চালাতে পারবে না। শুধু
আগে থেকে নিবন্ধিত, অনুমোদিত tool call করতে পারবে। উদাহরণ: -
get_current_time - open_app - set_flashlight - set_media_volume -
create_reminder - read_calendar - start_ocr - call_contact -
execute_routine

সব tool-এর input schema ও validation থাকবে।

6.4 Action dispatcher: প্রতিটি action-এর আগে intent, parameters,
permission, Android API support, confirmation requirement যাচাই করবে।
Action শেষে ফলাফল বাংলায় বা ইংরেজিতে জানাবে।

সম্ভাব্য permission/API access: - RECORD_AUDIO - CAMERA -
POST_NOTIFICATIONS - FOREGROUND_SERVICE - প্রয়োজনীয় foreground service

Android version অনুযায়ী permission behavior যাচাই করবে।

Permission rules: - Runtime request-এর আগে explanation দেখাবে। - Denial
হলে crash করবে না। - Feature-specific permission চাইবে। - অপ্রয়োজনীয়
SMS/Contacts/Location access নেবে না। - BIND_ACCESSIBILITY_SERVICE-এর
মতো service protection permission-কে runtime permission হিসেবে request
করবে না। - SYSTEM_ALERT_WINDOW ও DND access special access হিসেবে
পরিচালনা করবে। - Foreground service type ও notification requirements
ঘোষণা করবে। - Google Play policy ও privacy requirements মানবে।
